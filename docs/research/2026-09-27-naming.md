# Naming check (2026-09-27)

The working name `agent-canary` / `canary` collides with runcanary.ai (a YC company doing PR-time AI code verification) and with canary-named repos in the same space. These are lookups only; nothing was registered. A 404 from PyPI's JSON API does not guarantee the name can be registered, because PyPI blocks some prohibited and previously deleted names.

| Candidate | PyPI | npm | GitHub / product collisions | Verdict |
|---|---|---|---|---|
| **davylamp** (CLI `davy`) | free | free | none found; `davy` is free on PyPI and Homebrew, taken on npm | Strong: "the safer instrument that replaced the canary" |
| **linecall** | free | free | tennis apps only | Strong: a line call is the referee's ruling on a close call |
| **refbench** | free | free | an academic vision benchmark (RefBench-PRO) | Viable: plain "referee + benchmark", but may read as "reference" |
| harnesswatch | free | free | "Harness" is Harness Inc.'s brand | Trademark-adjacent |
| agentdrift | taken, by a direct-concept package ("Detect when your AI agents get dumber") | free | — | Reject |
| bellwether, plumbline, assay, tripwire, driftcheck | taken or crowded in AI/devtools | — | several agent-drift repos | Reject |

Decision: **open** at the time; since decided, `pinbench` ([ADR-0010](../adr/0010-name-pinbench.md)). Renaming is cheap before launch: the package, the CLI entry point and the docs.
