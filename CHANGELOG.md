# Changelog

## 0.1.0 (2026-10-21)

First release.

- Git-native task suites in Harbor's task format, with pins over harness, exact version, model, options and environment.
- Execution through Harbor in Docker: Claude Code (verified on several versions and three models) and Codex 0.163.0. OpenCode is not supported yet.
- A paired mixture e-process on pass rate that may be checked after every batch, a futility look, and cluster-bootstrap intervals on cost, tokens and latency.
- Cost re-priced from token usage with a dated price table for Anthropic and OpenAI models.
- A rule-based "false success" verifier for "tests pass" claims (rules v3).
- Immutable, checksummed run bundles, a SQLite index and a static HTML report.
- Release watching on npm, Slack and GitHub-issue alerts, and an example scheduled workflow (not yet run on GitHub).
- A lifetime spending ledger per credit pool, per-trial caps and dry runs.
- The October 2026 benchmark campaign: committed evidence and a script that rebuilds its report.
